2. Ciclo Detallado: Request → Response
sequenceDiagram participant Python as Python Script participant Requests as requests library participant HTTP as HTTP Client/Server participant Docker as Docker Container participant OSRM as OSRM Engine participant Graph as Road Network Python->>Requests: get_route_details(origin, waypoints) Requests->>HTTP: GET /route/v1/driving/{lon,lat};{lon,lat}?overview=false HTTP->>Docker: Route request on port 5000 Docker->>OSRM: Process routing query OSRM->>Graph: Find shortest path using MLD Graph-->>OSRM: Distance & duration OSRM-->>Docker: Route result Docker-->>HTTP: JSON response (status 200) HTTP-->>Requests: {"code":"Ok","routes":[...]} Requests-->>Python: Dictionary with distance/duration Python->>Python: Use data in bundling logic
Flujo temporal (típicamente <100ms):
  1. Python prepara coordenadas (restaurante → cliente)
  2. Envía GET HTTP request a localhost:5000
  3. Docker recibe en puerto 5000
  4. OSRM carga grafo de carreteras en RAM
  5. Ejecuta algoritmo MLD (Multi-Level Dijkstra)
  6. Retorna JSON con distance (metros) y duration (segundos)
  7. Python procesa resultado para bundling/asignación

5. Formato de Requests HTTP → OSRM

📍 Step 1: Preparar Coordenadas

Convertir de (lat, lon) a (lon, lat) porque OSRM usa formato lon,lat

# Python origin = (24.1440, -110.3115) # (lat, lon) waypoint = (24.1560, -110.2980) # Convertir para OSRM coords = f"{origin[1]},{origin[0]}" # "-110.3115,24.1440" coords += f";{waypoint[1]},{waypoint[0]}" # "...;-110.2980,24.1560"

🔗 Step 2: Construir URL

Crear endpoint GET completo con parámetros

url = "http://localhost:5000/route/v1/driving/" + coords + "?overview=false" # Resultado: # http://localhost:5000/route/v1/driving/-110.3115,24.1440;-110.2980,24.1560?overview=false

📤 Step 3: Enviar Request

Usar requests library con timeout de seguridad

response = requests.get(url, timeout=60) response.raise_for_status() # Lanzar error si status != 200 data = response.json()

📥 Step 4: Procesar Response

Extraer distance y duration del JSON

if data.get('code') == 'Ok': route = data['routes'][0] distance_meters = route['distance'] # 4231.5 duration_seconds = route['duration'] # 305.2 else: # Error: NoRoute, InvalidCoordinates, etc return None

Estrategia de Resiliencia:
  • 🟢 Caso Normal: OSRM responde correctamente → usar datos reales
  • 🔴 OSRM No Disponible: Fallback a distancia euclidiana + estimación de tiempo
  • ⚠️ Coordenadas Inválidas: Detectar y loguear, usar fallback
  • ⏱️ Timeout: Después de 60 segundos, asumir OSRM está lento
